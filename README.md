# RCB IPL Mega Auction Strategy

This project presents a data-driven SQL analysis to design an optimized
auction strategy for Royal Challengers Bangalore (RCB) in the IPL.

---

## 📊 Project Overview

The analysis leverages historical IPL ball-by-ball and match-level data
to identify player performance trends, venue impact, and strategic gaps
in RCB’s squad composition.

---

## 🎯 Key Objectives

- Analyze historical batting and bowling performances
- Identify consistent high-impact players across seasons
- Study venue and toss impact on match outcomes
- Propose data-backed auction recommendations for RCB

---

## 🗂 Dataset Overview

The project uses 20 normalized tables including:

- Ball_By_Ball – Delivery-level match data
- Matches – Match results and metadata
- Player – Player master information
- Team – Team details
- Season – IPL seasons
- Venue – Match venues
- Wicket_Taken – Wicket events
- Extra_Runs – Extra runs conceded

---

## 🛠 Tools & Techniques

- MySQL
- Complex joins and aggregations
- CTEs and window functions
- Views for reusable logic
- Performance metric calculations

---

## 📈 Key Insights

- RCB heavily depends on top-order batting
- Lack of consistent all-rounders impacts balance
- Bowling-first strategy yields better results at home
- Death-over bowling remains a critical weakness

---

## 🏏 Auction Strategy Recommendations

- Invest in reliable middle-order batsmen
- Prioritize all-rounders for flexibility
- Target specialist death-over bowlers
- Build a balanced squad, not star-heavy

---

## 🏁 Conclusion

This project demonstrates how SQL-driven analytics can transform raw
sports data into actionable strategic insights for IPL auction planning.
